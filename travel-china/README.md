# travel-china

朱红、水墨与纸张质感的中国景点静态展示站。

## 内容规模

- 182 个景点
- 覆盖 34 个省级行政区
- 182 个独立详情页
- 182 张本地图片
- 首页地图支持缩放、拖动和标记跳转
- 支持按省份和景点类型筛选
- 详情页包含景点概览、必看亮点、游览节奏、行前提示和信息来源

## 本地预览

这是纯静态网站，不需要安装依赖或启动构建工具。可以直接双击 `index.html`，也可以在项目目录运行：

```bash
python3 -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/index.html`。

## 目录结构

```text
index.html                 首页、地图、筛选和景点卡片
assets/style.css           统一视觉样式
assets/mapdata.js          地图边界与投影数据
assets/spots.js            第一组景点数据
assets/more-spots.js       景点扩展数据
assets/nature-spots.js     自然景观数据
assets/added-spots.js      本批次扩展景点数据
img/                       本地景点图片
*.html                    景点详情页
```

## 使用说明

- 地图标记可以点击进入对应详情页。
- 地图支持鼠标滚轮缩放、拖动和重置视图。
- 首页筛选会同步更新景点卡片和地图标记。
- 详情页中的门票、开放时间、交通和临时管控信息，出发前应以景区及相关部门的最新公告为准。
- 图片说明统一为：`图片由AI从互联网搜索获取，侵删`。

## 发布检查

发布前请确认：

1. `index.html`、`assets/` 和 `img/` 位于同一项目目录。
2. 所有详情页和图片保持相对路径，不依赖运行时图片接口。
3. 不要删除 `assets/mapdata.js` 或数据文件。
4. 若增加景点，应同时增加数据记录、详情页、本地图片、首页卡片和地图标记，并进行全量去重。
5. 若更新开放时间、票价或交通信息，应重新核对来源和更新时间。

本项目为静态展示资料，正式出行请以景区官方信息为准。
