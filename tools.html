二维码生成

输入文本、链接或任意内容后立即生成二维码。短文本默认使用较高纠错与紧凑尺寸，较长内容会自动放宽尺寸并适度降低纠错级别，避免过度压缩影响扫码。

自适应尺寸 + 纠错
  • 120 字以内：220×220，H
  • 121-260 字：280×280，H
  • 261-500 字：340×340，Q
  • 500 字以上：420×420，M

预览区域

暂无二维码
默认策略 短内容优先高纠错，兼顾打印、转发和截图场景。
长文本优化 内容变长后自动加大尺寸并下调纠错等级，优先保证可扫性。

Base64 编码 / 解码

支持普通文本进行 Base64 编码与解码。

URL Encode / Decode

用于对 URL 参数进行编码和解码，适合 querystring 与路径片段处理。

时间戳转换

支持 Unix 时间戳与本地日期时间互转，可一键切换秒级 / 毫秒级。

MD5 / SHA-256 哈希

对输入文本生成 MD5 或 SHA-256 摘要值，适合校验与快速比对。

文本大小写转换

支持转大写、转小写、首字母大写、单词首字母大写。

JWT 解析

解析 JWT 的 Header 和 Payload，显示签名部分，并把过期时间转为可读日期。

正则测试

输入正则表达式和测试文本，支持 g / i / m 标志，快速查看匹配结果。

UUID 生成

支持生成单个或多个 UUID v4，方便测试、数据构造和接口调试。

最多一次生成 100 个 UUID。

URL 解析

拆分 URL 的协议、用户名、主机、端口、路径、查询参数和锚点。

HTML 实体编解码

在本地完成 HTML 特殊字符转义和还原，适合处理网页片段与接口数据。

随机密码生成

使用浏览器加密随机数生成密码，不上传内容；可选择长度和字符集。
